# POS คาเฟ่ — คู่มือติดตั้ง (Web + Google Sheet)

ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอป POS (หน้าขาย, คิว, บิล, รายงาน, เมนู, ตั้งค่า, จอลูกค้า) |
| `Code.gs` | โค้ดหลังบ้านที่วางใน Google Apps Script |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | ทำให้ติดตั้งเป็นแอปบนแท็บเล็ตและเปิดได้แม้ไม่มีเน็ต |

ใช้เวลาติดตั้งประมาณ 15–20 นาที ไม่มีค่าใช้จ่าย

---

## ขั้นที่ 1 — สร้าง Google Sheet และ Apps Script

1. เปิด Google Sheets แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อ เช่น `POS คาเฟ่ - ข้อมูลร้าน`
   (ใช้บัญชี Google ของร้าน ไม่ควรใช้บัญชีส่วนตัวของพนักงาน)
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทิ้ง แล้ววางเนื้อหาทั้งหมดจากไฟล์ `Code.gs` ในชุดนี้
4. แก้บรรทัด `const SHOP_KEY = 'CHANGE-ME-1234';` เป็นรหัสของร้าน
   เช่น `'mycafe-7Kp29x'` (ภาษาอังกฤษ/ตัวเลข ยาวอย่างน้อย 8 ตัว และจดไว้ใช้ในขั้นที่ 3)
5. กด 💾 บันทึก
6. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **▶ Run**
   - ครั้งแรก Google จะขอสิทธิ์ ให้กด *Review permissions* → เลือกบัญชี → *Advanced* → *Go to … (unsafe)* → *Allow*
     (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ผ่านการรับรองของ Google)
7. กลับไปที่ชีต จะเห็นแท็บ `Menu`, `Orders`, `OrderItems`, `สรุปรายวัน`, `เมนูขายดี`, `สรุปตามช่องทางชำระ`

## ขั้นที่ 2 — เปิดให้แอปเชื่อมต่อได้ (Deploy)

1. ใน Apps Script กด **Deploy → New deployment**
2. กดรูปเฟือง ⚙️ แล้วเลือก **Web app**
3. ตั้งค่า
   - Description: `POS v1`
   - **Execute as: Me**
   - **Who has access: Anyone**
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ขึ้นต้น `https://script.google.com/macros/s/` และลงท้าย `/exec`)

> **แก้โค้ดใน Code.gs ภายหลัง** ต้องกด **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
> ถ้าทำแบบนี้ URL จะเหมือนเดิม ไม่ต้องไปแก้ในแอป แต่ถ้ากด New deployment จะได้ URL ใหม่

## ขั้นที่ 3 — นำหน้าเว็บขึ้นออนไลน์ (เลือกวิธีใดวิธีหนึ่ง)

**วิธี A: Netlify Drop (ง่ายที่สุด)**
1. ไปที่ https://app.netlify.com/drop แล้วสมัครหรือล็อกอิน (ฟรี)
2. ลาก **โฟลเดอร์** `cafe-pos` (ที่มีไฟล์ index.html) ไปวางในหน้าเว็บ
3. จะได้ลิงก์ เช่น `https://xxxx.netlify.app` ตั้งชื่อใหม่ได้ใน *Site settings → Change site name*
4. แก้ไฟล์แล้วอยากอัปเดต: เข้าเว็บไซต์ของร้านใน Netlify → แท็บ *Deploys* → ลากโฟลเดอร์ไปวางอีกครั้ง

**วิธี B: GitHub Pages**
1. สร้าง repository ใหม่ใน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. *Settings → Pages → Branch: main / root → Save*
3. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ขั้นที่ 4 — ตั้งค่าในแอป

1. เปิดลิงก์จากขั้นที่ 3 บนเครื่องที่ใช้ขาย
2. ไปที่หน้า **ตั้งค่า** (ใส่รหัสผู้จัดการ ค่าเริ่มต้นคือ `1234` และ**ควรเปลี่ยนทันที**)
3. ในการ์ด **เชื่อมต่อ Google Sheet**
   - Web app URL ใส่ URL จากขั้นที่ 2
   - รหัสร้าน ใส่ค่า `SHOP_KEY` จากขั้นที่ 1
4. กด **บันทึก & ทดสอบการเชื่อมต่อ** แล้วเลือกว่าจะใช้เมนูชุดไหนเป็นหลัก
5. ไฟสถานะที่มุมบนจะเป็นสีเขียว พร้อมข้อความ "บันทึกขึ้นชีตแล้ว"

## ขั้นที่ 5 — ติดตั้งเป็นแอปบนแท็บเล็ต

- **Android (Chrome):** เมนู ⋮ → *ติดตั้งแอป* หรือ *เพิ่มลงในหน้าจอหลัก*
- **iPad (Safari):** ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
- **PC (Chrome/Edge):** กดไอคอนติดตั้ง ⊕ ที่แถบที่อยู่

## จอลูกค้า (จอที่สอง)

ใช้กับคอมที่ต่อจอสองจอ กดปุ่ม 🖥️ จอลูกค้า แล้วคัดลอกลิงก์ (ลงท้าย `#customer`) ไปเปิดในหน้าต่างใหม่
ลากหน้าต่างไปไว้ที่จอที่หันให้ลูกค้า แล้วกด F11 ให้เต็มจอ
จอลูกค้าต้องเปิดใน**เบราว์เซอร์เดียวกันบนเครื่องเดียวกับหน้าขาย**

## การทำงานของระบบ

- **บันทึกบิล:** กดจ่ายแล้วบิลจะบันทึกในเครื่องทันที ขายต่อได้เลย ระบบจะส่งขึ้นชีตเบื้องหลังทุก 15 วินาที หรือทันทีที่มีบิลใหม่
- **เน็ตหลุด:** ไฟสถานะจะเป็นสีแดงพร้อมจำนวนบิลที่รอส่ง พอเน็ตกลับมาระบบจะส่งเอง บิลไม่ซ้ำเพราะใช้รหัสบิลตรวจซ้ำ
- **ยกเลิกบิล / เปลี่ยนสถานะคิว:** ส่งขึ้นชีตตามไปด้วย
- **เมนู:** แก้ได้ทั้งในแอป (ส่งขึ้นชีตให้) หรือในชีต `Menu` ถ้าแก้ในชีต แอปจะดึงเมนูใหม่ตอนเปิดแอป หรือเมื่อกด "ดึงเมนูจากชีต"
  - เพิ่มเมนูในชีตได้เลย ปล่อยช่อง `id` ว่างไว้ ระบบจะสร้างให้
  - `isDrink` = เป็นเครื่องดื่ม (เลือกร้อน/เย็น/ปั่นได้), `active` = เปิดขาย, `sort` = ลำดับที่แสดง
- **รายงาน:** ดูได้ในแอป หรือดูในชีต `สรุปรายวัน` / `เมนูขายดี` ซึ่งเจ้าของเปิดจากมือถือได้

## ข้อควรระวัง

- **ห้ามแก้หรือลบแถวในชีต `Orders` / `OrderItems` ด้วยมือ** ถ้าจะยกเลิกบิล ให้ยกเลิกจากในแอป
- **เครื่องนี้เป็นที่เก็บข้อมูลหลัก:** ถ้าล้างข้อมูลเบราว์เซอร์ บิลที่ยังไม่ได้ส่งขึ้นชีตจะหาย ควรดูให้ไฟเป็นสีเขียวก่อนปิดร้าน
- **ใช้ได้ครั้งละหนึ่งเครื่องขาย:** เลขคิวนับแยกในแต่ละเครื่อง ถ้าจะใช้หลายเครื่องพร้อมกัน ค่อยย้ายฐานข้อมูลไป Supabase ภายหลัง
- **เก็บ SHOP_KEY และลิงก์ /exec เป็นความลับ** ใครมีทั้งสองอย่างจะส่งข้อมูลเข้าชีตได้

## เมื่อต้องการย้ายไปฐานข้อมูลจริง (เช่น Supabase)

โค้ดที่คุยกับชีตอยู่ในส่วน `Google Sheet sync` ของ `index.html` ทั้งหมด (`enqueue`, `flush`, `api`, `pullMenu`)
และโครงชีตก็ตรงกับตารางฐานข้อมูลอยู่แล้ว (`Menu`, `Orders`, `OrderItems`)
ตอนย้ายจึงเปลี่ยนแค่ส่วนนี้ แล้ว export ชีตเป็น CSV ไป import ได้เลย
